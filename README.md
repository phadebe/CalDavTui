# CalDavTui

A calendar interface that combines all your different calendars: work, school, personal, under one interface. This project exists because I realised at some point that managing all my calendars across all my devices was impossible. I use Gmail on my phone for my personal calendars, Outlook for school, Thunderbird still for school (since Linux doesn't have native support for Microsoft 365 apps, and using an emulator is resource heavy and impractical), Gmail still on my laptop, KMail on my second PC and so on and so on.. We aim to simplify the syncing and managing of any and all your calendars, across all platforms. 

To do this we use the CalDav protocol to sync across virtually any platform ensuring that you only need to update your calendar once to view your events on any device of your choosing.

The interface is still largely under development (we're still working on the MVP), but you can expect a working platform soon, so star this repo (or follow us on GitHub) to get updates on the project.
